## The system

The canonical configuration lives in `@kkb/agents`, inside my `kkb` monorepo, versioned alongside the code it operates on.

### Portable context

One short bootstrap file (`GLOBAL.md`) defines shared rules and authority boundaries for Claude Code, Codex, and Pi. A router skill (`kkb`) loads task-specific guidance for engineering, design, delivery, communication, and browser verification only when a task needs it, keeping default context small and vendor-independent.

### Skills and verification

Repeatable workflows live as skills rather than one-off prompts: opening PRs, supervising them through CI and review, and turning corrections into narrow updates to instructions. Alongside my own skills, I maintain a pinned, customized copy of `pstack` engineering playbooks. Package changes are gated by integrity tests and agent eval runs before rollout.

### The sync CLI

A custom CLI (`kkb-agents`, written in TypeScript and Effect on Bun) deploys skills and global instructions across harnesses and machines from a single merged commit. It records what it wrote, reports drift, and refuses to overwrite local edits.

## How work lands

Agents deliver changes as small, reviewable slices and stacked PRs. Implementation and review deliberately cross model families, paired with automated CI, browser or runtime checks matched to the failure mode, and human approval before anything merges or deploys. When a session surfaces a recurring mistake, the fix goes back into the instructions, skills, or tests so the system compounds instead of repeating the same correction.

## Applied work

### Gist GEO at ProRata AI

I led engineering on Gist GEO, ProRata's generative engine optimization product, from initial architecture through its alpha with first customers, owning its agentic workflows, AI-reviewed CI, and team engineering practices.

### kkb-audio

I architected [kkb-audio](/software/kkb-audio) and delivered it with coding agents, pairing strict real-time Rust and WebAssembly invariants with a documented verification record for every milestone.

### Research pipelines and this site

A nightly pipeline of sandboxed Pi agent workers handles structured background research, and this site's late-2026 redesign shipped in stacked PRs with cross-model review and local-backend browser verification.
