kkb-audio is experimental. The engine is still in validation, and it has no public API yet.

The code is public on [GitHub](https://github.com/kalynbeach/kkb-audio). You can try the demo at [kkb-audio.vercel.app](https://kkb-audio.vercel.app).

## The engine

In the browser, the engine runs as WebAssembly inside an AudioWorklet. On macOS, it runs as native code through CPAL. Each host handles its own files, devices and lifecycle outside the engine.

## What works so far

- An offline kernel that never allocates while it renders
- That same kernel in a browser AudioWorklet and on native macOS
- Bounded PCM transport over ring buffers
- A compiled render plan with mixing and sample-timed gain automation
- Peak and RMS levels from the rendered output

## WavePlayer

WavePlayer is a local audio player built on the engine. It plays WAV and MP3 files from your computer, up to 100 at a time, and prepares only the active track.

It converts between 44.1 and 48 kHz. It supports sample-accurate seeking, A/B loops, volume and mute.

Audio can't wait on a file read or a UI update. A worker decodes files and hands PCM to the Rust engine in an AudioWorklet, so file and interface work stay out of the render callback. A WebGPU oscilloscope draws the left and right channels as an XY trace.

## Where it came from

I've built a line of wave-named audio projects since 2021. wavy, a live audio visualizer, came first in 2021. wave-visions followed in 2023, wave-player-2024 in 2024 and wave-player in 2025.

wave-player-next ran from July to October 2026. kkb-audio started on August 28, 2026, and replaced it.

I designed the architecture of kkb-audio and built it with coding agents.

## kkb-audio and kkb

kkb-audio works alongside [`kkb`](/drafts/kkb), my main monorepo. The player on this site comes from `kkb`, not from kkb-audio. It runs on the TypeScript audio package in `kkb` and on Kevelle's wave-player block.

I'm building kkb-audio as the Rust foundation for my audio software from here on.
