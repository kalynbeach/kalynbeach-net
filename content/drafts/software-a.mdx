## Kevelle

Kevelle is my design system, named after my middle name. I design it in Paper and publish it as a 91-item shadcn registry at [registry.kkb.systems](https://registry.kkb.systems).

It has more than 70 React components and blocks for audio instruments, including an oscilloscope, a waveform, binaural beats and a wave player. Its look comes from machine reports, hardware labels and oscilloscope traces, with sharp, high-contrast surfaces and 1px dither. This site installs it from the registry.

## kalynbeach.net

This is my personal site. I started it in December 2024, and its code is on [GitHub](https://github.com/kalynbeach/kalynbeach-net).

It runs on Next.js 16 and React 19. Pages are MDX. Convex stores the data and audio, and Clerk handles sign-in.

In October 2026 the site moved to Kevelle. The November redesign split each page into a sidebar, a centered column and a rail for what's live. Claude Code and Codex built it as stacked PRs, and a second model reviewed each one.
