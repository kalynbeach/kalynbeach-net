## What's in it

### Apps

- The web app at [kkb.systems](https://kkb.systems), with audio and visual experiments: an oscilloscope driven by oscillators or live mic input, a web audio player and a binaural beat generator
- The registry app at [registry.kkb.systems](https://registry.kkb.systems), which publishes Kevelle and its components and blocks, including the Kevelle Oscilloscope, Waveform and WavePlayer that this site uses

### Packages

- An audio package, with the oscilloscope that renders on kkb.systems
- A headless audio engine for the browser
- A shared React UI library
- Ableton Live extension experiments
- The agent system, described below

### Stack

- Bun workspaces and Turborepo
- TypeScript 7, Next.js, React, Tailwind and Effect 4
- Oxlint and Oxfmt

## Agent system

[Kalyn: a line on why your agent system lives in kkb.]

### Instructions and skills

- One global instruction file that Claude Code, Codex and Pi all read first
- A router skill that loads guidance only when a task needs it, such as engineering, design, delivery or browser work
- My own skills for opening PRs, supervising them through CI and review, writing HTML reports, and turning my corrections into fixes to my instructions
- A copy of pstack, an open-source set of engineering principles and playbooks for agents from Cursor

### The kkb-agents CLI

- Written in Effect 4
- Syncs one release of the skills and instructions to every agent on every machine
- Refuses to overwrite a local edit, and its `check` command reports drift

### Review

- Agents open their work as stacked PRs, and I review and merge them
- Claude Code GitHub Actions review each PR
- GPT-6.1-sol checks the work Claude writes

The [Agents](/drafts/agents) page has the full history.

## Kevelle

- My design system, named for my middle name
- Designed in Paper and built in kkb
- A 91-item shadcn registry at [registry.kkb.systems](https://registry.kkb.systems), with more than 70 React components and audio blocks
- Departure Mono sets titles, labels and values, ABC Areal sets body text and controls, and Timeless Serif sets long-form prose
- This site installs it from the registry, so a Kevelle change lands in kkb first
