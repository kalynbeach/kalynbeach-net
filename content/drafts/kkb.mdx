`kkb` holds most of what I build. I started it in January 2026. Its agent work goes back to kkb-code in June 2025.

The repository is private, so this page describes it instead of linking to it.

## What it holds

- My agent system, with the instructions, skills and tools my coding agents run on
- My audio and visual work
- A shared React UI library
- The Kevelle design system and the shadcn registry that publishes it

## Agent system

My coding agents run in Claude Code, Codex and Pi. They all share one set of instructions and skills, and that set lives in `kkb` next to the code.

GLOBAL.md is the instruction file every agent reads first. The `kkb` router skill loads more guidance only when a task needs it, such as engineering, design, delivery or browser work.

My own skills cover opening pull requests and supervising them through CI and review. Others write HTML reports or turn my corrections into narrow fixes to my instructions.

My agents also follow pstack, an open-source set of engineering principles and playbooks for agents from Cursor. `kkb` keeps its own copy.

The `kkb-agents` CLI is written in Effect 4. It reads one release of `main` and syncs the skills and instructions to Claude Code, Codex and Pi on every machine I use. It refuses to overwrite local edits, and its `check` command reports drift.

Agents open their work as stacked pull requests. Claude Code GitHub Actions review each one. Every agent that checks work runs on a second model family, so GPT-6.1-sol reviews what Claude writes. I review and merge.

The [Agents](/software/agents) page has the longer history.

## Audio and visual work

Most of what I make involves sound. These are the audio and visual pieces in `kkb`:

- A web audio player
- A WebGPU oscilloscope, driven by oscillators or live mic input
- A binaural beat generator
- A headless audio engine package for the browser
- Ableton Live extension experiments

The oscilloscope draws with Phosphor, my WebGPU renderer. Phosphor falls back to WebGL2 where WebGPU is missing. It recreates the glow and persistence of an analog CRT oscilloscope from live audio. You can try the oscilloscope at [kkb.systems](https://kkb.systems).

## Kevelle and the registry

Kevelle is my design system, and it's named for my middle name. I design it in Paper and build it in `kkb`.

`kkb` publishes Kevelle as a shadcn registry of 91 items at [registry.kkb.systems](https://registry.kkb.systems). The items include more than 70 React components and audio instrument blocks for the oscilloscope, waveform, binaural beats and wave player.

Kevelle's look is sharp and high contrast. Its references are machine reports, hardware labels, hairline grids, dithered meters and oscilloscope traces.

In Kevelle, Departure Mono sets titles, labels and values. ABC Areal sets body text and controls, and Timeless Serif sets long-form prose.

This site installs Kevelle from the registry. A change to a Kevelle component lands in `kkb` first, then reaches this site when I reinstall it.

## How it's built

`kkb` uses Bun workspaces and Turborepo. The code is TypeScript 7, with Next.js, React, Tailwind and Effect 4. Oxlint lints it and Oxfmt formats it.
