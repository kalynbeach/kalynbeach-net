## How I work with agents

I've built with language models since 2023 and with coding agents since 2024. Claude Code, Codex and Pi work from one versioned set of my instructions and skills. My `kkb-agents` CLI syncs that set to every agent and machine and reports any copy that drifts. Work lands as stacked pull requests. A model from a second family reviews each one. I review what ships.

Overnight, a pipeline of sandboxed Pi agents runs research within my usage limits. Each morning it leaves reports I can review.
