## kkb-audio

A portable real-time audio engine in Rust running in the browser through WebAssembly and natively on macOS, built around allocation-free rendering and lock-free streaming. It powers an experimental local WavePlayer with a WebGPU phosphor oscilloscope and an interactive engine lab at [kkb-audio.vercel.app](https://kkb-audio.vercel.app) ([source](https://github.com/kalynbeach/kkb-audio)).

## Kevelle

My personal design system, distributed as a shadcn registry at [registry.kkb.systems](https://registry.kkb.systems). It lives in my `kkb` monorepo alongside a set of browser audio and visual experiments: a WebGPU oscilloscope and spectrogram, an AudioWorklet synth with Web MIDI, binaural beats, and an Ableton Live set viewer.

## Agents

I've been building with AI agents since 2023, moving from early music tools to `@kkb/agents`: a portable setup of shared instructions, skills, evals, and a custom sync CLI shared across Claude Code, Codex, and Pi.

## This site & ui-lab

This site is built on Kevelle, with a persistent waveform stage and music player that stay live across routes ([source](https://github.com/kalynbeach/kalynbeach-net)). [ui-lab](https://github.com/kalynbeach/ui-lab) is a companion sandbox for WavePlayer variants and interface studies.
